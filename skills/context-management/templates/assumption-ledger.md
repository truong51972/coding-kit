# Assumption Ledger (Optional)

Use only when a project explicitly designates a cross-task assumption ledger.
For one-off work, record material assumptions in the existing task/handoff
artifact instead. This template is **not** installed by `init`.

## Provisional

- [ ] ASM-001 — provisional — <scoped, falsifiable premise>
  Scope: <component/environment/revision>
  Decision affected: <consequential choice>
  Basis: <observation or source pointer, and observation time>
  Verify by: <test or authority check; invalidation condition>
  Owner: <single designated writer>

## Resolved

- [x] ASM-000 — verified / rejected / retired — <scoped claim>
  Resolution: <specific outcome and applicable scope>
  Evidence: <authoritative source or check>
  Successor: <context fact or canonical record, if any>

Do not equate a checked box, repetition, or agent endorsement with verification.
Do not copy operational holds or task history here.
